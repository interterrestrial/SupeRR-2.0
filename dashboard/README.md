# SupeRR Selector Season 2 dashboard

Interactive dashboard for the validated 2022–2026 IPL and T20I pressure-performance rankings.

## What it does

- Switches between batter and bowler rankings.
- Supports IPL and T20I as independent mode selections; selecting both uses the validated combined rating.
- Provides a searchable multi-select containing every national team in the source mapping.
- Shows only players who pass the Reliable evidence rule for the active ranking mode.
- Explains format evidence, pressure-versus-ordinary performance, weighted metric contributions, and bootstrap uncertainty.
- Preserves the approved official Top 10 when both modes and all teams are selected.

The UI reads the generated static bundle at `public/dashboard_data.json`. It does not recalculate or alter player ratings.

## Local development

Requires Node.js **22.x**, matching `package.json` and `.nvmrc`.

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```

The production build is a standard Next.js application with no database, server-side scoring, or Cloudflare dependency.

## Vercel deployment

Deployment is deferred until report and dashboard review is complete. The commands below are a handoff guide; a permanent public URL is not yet established.

Import the repository into Vercel and set `dashboard` as the Root Directory. Vercel will detect Next.js and use `npm run build` automatically. No environment variables are required.

For CLI deployment from this directory:

```bash
npx vercel
```

Use `npx vercel --prod` after the preview is approved.

## Structure and styling

```text
app/
  page.tsx          Route entry point
  dashboard.tsx     Filters, rankings and player evidence
  globals.css       Navy, pink and white report theme
  layout.tsx        Page metadata and shared layout
public/
  dashboard_data.json  Reviewed static evidence snapshot
```

The UI uses Arial, matching the editable methodology report, with navy text and headers, pink active controls and pressure comparisons, and white evidence panels. Desktop places the ranked player list left and selected-player details right. Mobile stacks the list above the details.

The single data snapshot is generated by `Phase_7B_Dashboard_Data_Foundation.ipynb` in the repository root. Do not hand-edit player scores in the JSON. Regenerating it requires the local analytical outputs and authorised source data; running the website does not.

No database, login, Cloudflare service or environment variables are needed. Local dependencies, `.next` build output and `.vercel` account state are excluded from Git.
